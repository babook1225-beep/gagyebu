# 가계부 · 카드내역 가져오기

카드사 이용내역 엑셀을 올리면 목록으로 보여주고, 적요·메모를 확인한 뒤 **완료**하면
구글 스프레드시트 가계부의 월 탭(`YYYY.MM`) 날짜 칸에 넣어 주는 Apps Script 도구.

- 이용일 기준으로 해당 월 탭, 그날 칸에 입력 (지출 5–14행, 날짜마다 [적요, 금액])
- 같은 날 같은 적요는 금액 칸에 더하기 (`=a+b`), 메모는 `기존+새메모`
- 시트에 같은 금액이 ±2일 안에 이미 있으면 "이미 있음" → 체크해 두면 새로 넣지 않고 적요·메모만 수정
- 가맹점별 적요·메모를 기억해서 다음 달에 자동으로 채움

## 구조

- `src/` — 원본 (`parser.js` 엑셀 읽기, `plan.js` 시트 칸 계산, `app.js` 서버, `index.src.html` 화면)
- `dist/` — `python3 build.py` 결과. 시트의 Loader가 여기서 최신 코드를 받아 실행
- `apps-script/Loader.template.gs` — 시트의 Apps Script에 한 번만 붙여넣는 코드 (시트 ID만 채움)
